## 🧠 Problem-Solving Practice

Each problem focuses on understanding:

1. Problem statement
2. Input and output
3. Approach
4. Algorithm
5. Code implementation
6. Time complexity
7. Space complexity
8. Alternative approaches

Example:

```text
Problem
   ↓
Understand Input / Output
   ↓
Find Pattern
   ↓
Write Pseudocode
   ↓
Implement Solution
   ↓
Analyze Time & Space Complexity
   ↓
Try Alternative Approach
```
